## Sobre o projeto

O projeto consiste na modelagem de uma plataforma digital para gerenciamento de campanhas e personagens de RPG de mesa, inicialmente baseada no sistema de regras Dungeons & Dragons (D&D).

A plataforma tem como objetivo centralizar as informações de jogadores, mestres, personagens e campanhas, oferecendo ferramentas para auxiliar na organização e realização de sessões de RPG.

Entre as funcionalidades previstas estão a criação e gerenciamento de personagens, administração de campanhas, utilização de mapas, rolagens de dados e cálculos automáticos relacionados às regras do jogo.

O sistema contará com diferentes permissões para jogadores e mestres, permitindo que cada perfil tenha acesso às funcionalidades correspondentes às suas responsabilidades.
